# ShopEase Website 🛍️

ShopEase is a responsive e-commerce website built using HTML, CSS, and JavaScript. It provides a clean shopping interface with different product categories and a functional shopping cart.

## ✨ Features

- Responsive e-commerce website
- Home page with product categories
- Clothing section
- Handbags section
- Shoes section
- Makeup section
- Jewellery section
- Accessories section
- Shopping cart functionality
- Product images
- Interactive JavaScript features
- Clean and user-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
